# Ami3D M0

## Definition of done

M0 is complete when the repository contains:

1. A documented scene model.
2. A renderer interface that does not assume a specific CPU or backend.
3. A deterministic minimal scene fixture.
4. A documented AmiRender integration boundary.
5. CI-ready source layout.

## Scene model

The first scene core only needs:

- scene
- camera
- object
- transform
- mesh reference
- material reference
- light
- render settings

The M0 representation must remain small enough for classic Amiga memory budgets and serialisable for transfer to AmiRender.

## Renderer contract

A backend receives a scene plus render settings and produces one frame or tile.

Backends envisioned:

- local m68k reference renderer
- AmiRender remote backend
- future RTG/GPU-assisted backends where appropriate

## Compatibility principle

Classic format importers should translate into the Ami3D scene model rather than leak application-specific semantics throughout the core.
